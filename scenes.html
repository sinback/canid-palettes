🐺 Scene preview

Whole pixel-art scenes, as a canid would see them. Back to the color REPL.

What am I looking at?

Each scene is shown as it is on the left and as a canid would see it on the right. Pixel art uses a small palette, so every distinct color is translated once and the image is repainted from that table; the strip under each scene shows the table (original on top, simulated below), most-used colors first.

The images are read from images/ in the project, which is not checked in. To preview your own scenes, put PNGs there with these names and run npm run serve again.

For the intended preview, turn off Night Shift, f.lux or similar.
